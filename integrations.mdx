## Overview

ParyatechOS integrates seamlessly with your existing CRM, communication, and booking tools. You connect services to centralize client data, automate workflows, and eliminate manual spreadsheet updates.

<Callout kind="info">
  You need administrator access in both ParyatechOS and the target service before starting any integration.
</Callout>

## Connecting to CRM

You link your CRM to keep client records synchronized automatically.

<Tabs>
  <Tab title="Salesforce" icon="cloud">
    <Steps>
      <Step title="Generate API credentials">
        Create a connected app in Salesforce and copy the consumer key.
      </Step>
      <Step title="Configure in ParyatechOS">
        Navigate to Settings and paste your credentials.
      </Step>
    </Steps>
  </Tab>
  <Tab title="HubSpot" icon="link">
    <Steps>
      <Step title="Create private app">
        Generate an access token with contacts and deals scopes.
      </Step>
      <Step title="Connect account">
        Enter the token in the ParyatechOS integration panel.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Importing from Spreadsheets

You import client and itinerary data directly from spreadsheets.

<Steps>
  <Step title="Prepare your file">
    Ensure your CSV or Google Sheet contains columns for name, email, trip type, and dates.
  </Step>
  <Step title="Upload and map fields">
    Go to Data Import, upload the file, and map columns to ParyatechOS fields.
  </Step>
  <Step title="Review and confirm">
    Preview the first 10 rows before completing the import.
  </Step>
</Steps>

## Setting Up Webhooks

You configure webhooks to receive real-time updates when proposals are accepted or new queries arrive.

````json
{
  "url": "https://your-webhook-url.com/webhook",
  "events": ["proposal.accepted", "query.created"],
  "secret": "YOUR_WEBHOOK_SECRET"
}
````

## Automated Notifications

You enable Slack or email notifications for key events.

<CodeGroup tabs="cURL,JavaScript">
```bash
curl -X POST https://api.example.com/integrations/slack \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"channel":"#sales","events":["proposal.sent"]}'
```
```javascript
const response = await fetch('https://api.example.com/integrations/slack', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer YOUR_API_KEY' },
  body: JSON.stringify({ channel: '#sales', events: ['proposal.sent'] })
});
```
</CodeGroup>

<Expandable title="Advanced webhook security">
  You should validate the `X-Paryatech-Signature` header on every incoming request to prevent unauthorized calls.
</Expandable>
